# 2026년 10월 25일 공개 근거 점검과 보증금 안내 배포

## 실제 수행 범위

공개 출판본 024의 근거 428개를 대상으로 점검했다. 원천자료는 10월 20일 완료된 공식 자료 갱신과 독립감사의 활성 데이터베이스 해시에 결박한다. 원문 수집 시각과 법률 설명을 대조한 시각은 구분한다. 10월 20일 이후의 모든 법령 변경이나 후속 판례를 탐지했다고 주장하지 않는다.

- 현행 조문 409개: 원문 해시 동일 131개, 조문별 내용 영향 검토 278개.
- 판례 좌표 15개: 고유 사건 13건의 인용 법리와 조건을 개별 대조.
- 공식 문서 3개: 공포·시행 메타데이터 대조.
- 역사적 조문 1개: 과거 원문 재검증은 하지 않았으므로 원본과 기존 확인일 보존.
- 변화 안내 11개: 개별 설명·시행·적용례 대조 및 교정 전후 해시 보관.

검토 기록은 `fixtures/source-check-20261025/`에 있다. 갱신기는 검토 법령명뿐 아니라 정확한 조문, 개별 판례, 변화 안내의 입력 해시, 실제 교정문 반영을 모두 검사한다. 공식 원문 해시 불일치를 오래된 공포일만으로 통과시키지 않는다. 과거 출판 스냅샷은 변경하지 않고 새 출판본을 만든다.

## 사용자에게 영향을 주는 교정

고소·고발 접수와 구술 기록, 성희롱 관련 시정신청의 유형별 기산점, 미성년 성적 침해 피해의 시효 진행 정지, 처벌불원과 보험가입 특례의 차이, 소액사건 적용 범위, 개인 간 거래 신원정보, 상속권상실 절차별 사유를 교정했다. 선택 메모의 직접 복사와 자동 전송 금지도 실제 제품 동작에 맞췄다.

## 점검 비용과 날짜의 의미

점검은 글마다 같은 법령을 반복 읽는 방식이 아니다. 공유 근거의 원문 해시를 비교하고, 변경된 근거를 쓰는 글만 역의존 관계로 찾는다. 실제 의미 대조가 필요한 조문에는 검토 기록을 요구한다. 변화 탐지 자체는 모델 호출 없이 수행한다. 현재의 90일·180일은 변경을 자동 확정하는 날짜가 아니라 다음 점검의 최장 간격이다.

명시적 역사판은 오래됐다는 이유만으로 현행 설명 전체를 만료시키지 않는다. 다만 근거가 없거나 역사판 자체가 바뀌면 계속 차단·무효화한다. 원본 확인일을 새 날짜로 덮지 않는다.

## 문언과 개인정보 경계

공개 조문 문언은 해당 출판 근거와 활성 원문의 해시가 일치할 때만 표시한다. 손상 문자·원시 HTML이 남은 자료는 인용하지 않고 공식 원문 링크를 유지한다. 승인된 조문 읽기 자료의 기존 불변 원본은 임의 치환하지 않는다.

보증금 상황 선택은 기기 저장이나 외부 통신을 하지 않는다. 조건을 모르면 행동을 확정하지 않으며, 사용자가 명시적으로 복사·저장한 요약만 가져갈 수 있다. 컨시어지 작업공간 이동 전 정보 경계 안내를 유지하고 사건정보를 주소나 네트워크로 자동 전송하지 않는다.

## 검증

`npm run test:source-check`는 교정 역전, 검토 범위 확대, 근거 없는 날짜 갱신을 차단한다. 정규 출판 시험·주제 시험·과거 스냅샷 불변·현재 날짜 정적 빌드·실행 중 경로 점검을 함께 수행한다. 브라우저 시험은 네 화면 폭에서 사실분기, 조건부 행동, 초기화, 실제 문언, 복사·저장, 접근성, 무통신을 검사한다. 운영 배포 후 실제 주소에서 다시 확인해야 완료다.
